# Customer Churn Prediction Dashboard

An interactive **Power BI** dashboard for exploring customer churn patterns and supporting data-driven customer-retention decisions.

## Project file

The Power BI report is supplied as `CUSTOMER_CHURN_PREDICTION.pbix.zip`. Extract the archive, then open the `.pbix` file in **Microsoft Power BI Desktop**.

> **Upload note:** The project documentation is published here. The connected GitHub actions available in this session can create and update text files, but cannot transfer this uploaded binary archive or create a new repository. Upload the ZIP manually to this repository folder (or a dedicated repository) to make the report downloadable from GitHub.

## Suggested review areas

- Customer churn distribution and overall churn rate
- Customer segments with higher churn
- Service, contract, and payment patterns associated with churn
- Dashboard filters and interactive report navigation
- Retention opportunities suggested by the visual analysis

## Tools

- Microsoft Power BI Desktop
- Power Query (for data preparation, if used in the report)
- DAX (for measures, if used in the report)

## How to view

1. Download `CUSTOMER_CHURN_PREDICTION.pbix.zip` after it is uploaded.
2. Extract the ZIP archive.
3. Open the extracted `.pbix` file in Power BI Desktop.
